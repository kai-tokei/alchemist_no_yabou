# 錬金術師の野望

空から降ってくる星を手で捕まえるミニゲームです。
稲垣足穂の「星を売る店」という短編小説の「リビア人が星を捉える秘術を知っている」
というエピソードをもとに制作しました。

## 特徴
- 3D空間を描画するために、ピンホールカメラモデルを実装
- 四元数クラスを実装し、回転処理を簡略化
- ガウス分布を用いて、天の川を描画

## 使用技術
- Processing 4.5.2

## 実行方法
リポジトリをクローンし、Processingで実行します。
https://processing.org/

## 遊び方
- 十字キーで視点移動
- スペースキーでつかむ
